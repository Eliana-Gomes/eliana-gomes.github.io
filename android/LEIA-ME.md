# App Android da Parlia (Trusted Web Activity)

- Cópia do `twa-manifest.json` usado pelo Bubblewrap (sem segredos). O projeto Android fica fora do repositório, em `C:\Users\HP 840 G1\parlia-android`.
- A chave de assinatura (`parlia-upload.keystore`) e a senha NUNCA entram aqui: ficam em `C:\Users\HP 840 G1\parlia-chaves`.
- Para recriar o projeto noutro computador: instalar o Bubblewrap, pôr este arquivo numa pasta vazia e correr `bubblewrap update --skipVersionUpgrade` e depois `bubblewrap build`.
